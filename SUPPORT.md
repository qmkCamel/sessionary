# Support

Sessionary is an early project, so the best support channel is usually a GitHub
issue with enough context to reproduce the problem.

## Bug Reports

Use the bug report template and include:

- operating system
- Node, npm, and Rust versions
- whether you ran Tauri or browser preview
- affected data source: Codex, Claude Code, fixture, or fallback data
- steps to reproduce

Do not paste private prompts, responses, source code, customer data, or full
local logs into public issues. Trim or anonymize examples.

## Feature Requests

Use the feature request template. Please describe the workflow problem first,
then the proposed UI or data behavior.

For non-trivial proposals, expect an OpenSpec change before implementation.

## Security Issues

Use the process in [SECURITY.md](SECURITY.md). Do not disclose vulnerabilities
that could expose local session data in a public issue.
