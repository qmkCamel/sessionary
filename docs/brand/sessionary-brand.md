# Sessionary Brand Assets

Sessionary 的品牌图形表达的是本地 AI coding session ledger：纸张账本、session inbox 和错位时间线。

## Assets

- `src/assets/brand/sessionary-icon.svg`：桌面 app icon / 大尺寸头像。
- `src/assets/brand/sessionary-mark.svg`：透明背景 compact mark，适合应用侧栏、按钮和文档内嵌。
- `src/assets/brand/sessionary-logo.svg`：横向 logo，适合 README、发布说明和站点头部。
- `src/assets/brand/sessionary-mark-mono.svg`：单色 mark，适合低色印刷、mask 或受限场景。
- `public/favicon.svg`：浏览器预览 favicon。
- `src-tauri/icons/icon.png`：Tauri bundle 使用的 256px PNG icon。

## Palette

- Paper: `#fbfbf8`
- Paper strong: `#ffffff`
- Ink: `#1d2527`
- Line: `#d9ddd5`
- Sage: `#2f7770`
- Blue: `#2d67b4`
- Amber: `#a8671b`

## Usage

- App icon 使用圆角 paper tile。
- UI 内嵌优先使用 transparent compact mark。
- 横向空间充足时使用 horizontal logo；空间紧张时只用 compact mark。
- 不要拉伸、旋转或重新上色为高饱和渐变。
- 不要把该图形用于暗示云同步、远程监控或团队绩效管理。
